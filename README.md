# CatalogAI

AI-powered ecommerce listing generator for Amazon, Shopify, Etsy, Walmart, eBay, and TikTok Shop.

## Tech Stack

- Next.js
- FastAPI
- OpenRouter
- PostgreSQL (planned)
- Tailwind CSS
- TypeScript

## Features

- AI Listing Generation
- Marketplace-specific optimization
- Multi-platform support
- SEO optimization
- CSV export (planned)
